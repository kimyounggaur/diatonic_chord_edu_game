# 코드 크래프터: 조성 왕국 복원기

음계를 직접 배열하고, 음계에서 한 칸씩 건너뛰어 1·3·5음을 쌓는 모바일 우선 음악이론 퍼즐 웹앱입니다. 음계·화음 품질·로마 숫자·기능·진행을 소리와 함께 배웁니다. 한국어 UI와 390×844 / 320×568 화면을 기준으로 구현했습니다.

## 설치와 실행

Node.js 20.19 이상인 20.x 또는 22.12 이상이 필요합니다. 의존성의 정확한 버전은 `package-lock.json`에 고정되어 있습니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 Vite 주소를 엽니다. 기본 개발 주소는 `http://localhost:5173`이며, 앱 화면은 `/#map`, `/#codex`, `/#practice`, `/#challenge`로 이동할 수 있습니다.

```bash
npm run build
npm test
npm run test:coverage
```

`build`는 TypeScript 검사 후 `dist/`에 정적 배포 파일을 만듭니다. `test`는 Vitest 단위 테스트를 실행합니다. 빌드 결과의 로컬 확인은 `npx vite preview --host 0.0.0.0`으로 실행할 수 있습니다.

## 모바일 E2E

Playwright는 앱 서버를 자동으로 시작하지 않습니다. 먼저 별도 터미널에서 `npm run dev`를 실행하고, Playwright에 맞는 Chromium 실행 파일을 설치한 환경에서 테스트합니다.

```bash
npx playwright install chromium
npm run test:e2e
```

외부 개발 프리뷰나 배포 주소를 검사할 때는 이미 실행 중이며 접근 가능한 주소를 지정합니다.

```bash
PLAYWRIGHT_BASE_URL=https://your-preview.example npm run test:e2e
```

Windows PowerShell에서는 다음처럼 지정합니다.

```powershell
$env:PLAYWRIGHT_BASE_URL="https://your-preview.example"
npm run test:e2e
```

이미 설치된 Chromium을 사용할 때는 실행 파일을 지정할 수 있습니다. Linux의 `/usr/bin/chromium`이 있으면 설정이 자동으로 선택합니다.

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium PLAYWRIGHT_BASE_URL=https://your-preview.example npm run test:e2e
```

설정은 `playwright.config.ts`, 테스트는 `tests/e2e/game.spec.ts`에 있습니다. 390×844와 320×568의 두 프로젝트에서 음계 배열, 반음 선택, 오답 후 직접 재현, 드래그와 탭, 설정 유지, C 장조 6단계와 A 단조 해금을 검사하도록 구성했습니다. 테스트 러너의 12개 사례는 이번 환경에서 브라우저 실행 중 OS 소켓 제한으로 assertion 진입 전에 차단되어 통과로 집계하지 않았습니다. 실패 시 `test-results/`에 스크린샷·트레이스, `playwright-report/`에 HTML 결과를 남기도록 설정되어 있습니다.

별도 브라우저 프리뷰 조작으로 C 장조 6단계의 각 100점·별 3개 완료와 A 자연단조 해금, 세 번 오답 후 직접 재현, 새로고침 뒤 완료 7개·별 19개·해금 조성 2개의 유지, 여섯 도전의 진입·제출·결과, 포인터 드래그의 슬롯 교체를 확인했습니다. 390×844와 320×568 프리뷰에 가로 넘침이 없었습니다. 이 확인은 Playwright 테스트 파일의 실행 결과와 별도입니다. 실물 iPhone Safari·Android의 실제 터치와 오디오·PWA 동작은 아직 검증하지 않았습니다. 상세 근거는 `docs/IMPLEMENTATION.md`에 있습니다.

## 플레이 방법

- **모험 시작하기**를 누르고 **복원 시작하기**로 첫 임무에 들어갑니다.
- 카드를 탭하면 다음 빈칸에 들어갑니다. 바꿀 슬롯을 탭한 뒤 다른 카드를 선택하거나, 카드를 슬롯으로 드래그할 수 있습니다.
- 음계를 배열한 뒤 반음 두 구간을 찾습니다. 화음 탑은 자동으로 제시된 루트에서 3음과 5음을 직접 고릅니다.
- **듣기**와 블록 코드·아르페지오 재생은 감점이 없습니다. **힌트**는 문항당 사용 횟수에 따라 15점씩 차감됩니다.
- 세 번 오답이면 완성 경로를 보여 줍니다. **직접 다시 만들기**로 답을 지운 뒤 같은 과제를 직접 재현해야 통과합니다.
- 설정에서 음소거, 연주·효과음 음량, 음색, 모션 감소, 진동, 음이름 병기, ASCII 기호, 청음 시각 안내를 선택할 수 있습니다.

## 콘텐츠와 해금

| 범위 | 조성 | 지역 | 스테이지 |
|---|---:|---:|---:|
| 핵심 캠페인 | 장조 12 + 자연단조 12 | 상대조 12쌍 | 156 |
| 고급 거울 확장 포함 | 장조 15 + 자연단조 15 | 상대조 15쌍 | 195 |

각 지역은 장조 6단계, 자연단조 6단계, 상대조 비교 1단계로 생성됩니다. 공통 6단계는 조표 문 열기, 3도 계단, 품질 감정, 로마 숫자, 기능 다리, 진행 보스입니다. 195개 스테이지를 개별 복사하지 않고 조성 데이터와 템플릿으로 생성합니다.

C 장조부터 시작합니다. 현재 조성의 선행 단계를 완료하면 다음 단계로 갈 수 있고, 장조 진행 보스를 완료하면 상대단조가 열립니다. 두 조성의 12단계를 모두 완료하면 비교 보스에 진입할 수 있습니다. 비교 보스 완료 시 다음 지역의 장조가 열립니다. 지도에서 **고급 거울 지역 보기**를 켜면 F♯/D♯, C♯/A♯, C♭/A♭ 상대조 지역을 표시하며, 이 지역에도 순차 해금 규칙이 적용됩니다.

자유 연습과 도감은 캠페인 잠금과 별개로 30개 표기 조성을 살펴볼 수 있습니다. 화성단음계는 자유 연습의 별도 고급 모드입니다. 본편 자연단조의 v를 장화음 V로 바꾸지 않습니다.

## 도전의 탑

C 장조의 진행 코어 보스전을 완료하면 다음 여섯 모드가 열립니다. 조표 질주와 로마 숫자 변환에만 60초 제한이 있으며, 나머지는 시간제한이 없습니다. 결과는 현재 세션의 첫 시도 정답 수와 정확도로 표시하고 모험의 별·해금이나 영구 최고 기록을 변경하지 않습니다.

| 모드 | 내용 |
|---|---|
| 60초 조표 질주 | 조표와 장·단조 조건으로 조성 찾기 |
| 7개 화음 연속 구축 | C 장조 1~7도의 1·3·5를 직접 쌓기 |
| 로마 숫자 변환 | 현재 조성의 코드 이름을 로마 숫자에 연결 |
| 철자 오류 탐지 | 같은 소리라도 조표와 글자 순서를 지킨 표기 찾기 |
| 코드 품질 청음 | 합성음의 장·단·감 품질 구별, 시각 대체 지원 |
| 5도권 릴레이 | 완전5도 관계의 12개 음고 중심 연결 |

## 저장과 오디오

진행은 현재 브라우저의 `localStorage` 키 `chord-crafter-save`에 저장합니다. 완료 단계, 별, 해금, 개념별 숙련도, 복습 기록, 설정을 보관합니다. 설정에서 JSON 내보내기·가져오기가 가능하며, 초기화 전 확인 절차가 있습니다. 저장을 사용할 수 없어도 플레이는 계속하고 안내를 표시합니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있으므로 필요한 기록은 내보내 주세요.

Web Audio 합성음만 사용하며 외부 음원 파일을 내려받지 않습니다. 첫 사용자 동작 뒤 오디오를 시작하고, 화면이 숨겨지면 소리를 멈춥니다. 피아노형·마림바 등의 음색은 실제 악기 샘플이 아닌 합성음입니다. 앱 자체 클라우드 계정, 기기 간 자동 동기화, 마이크·실제 악기 인식, MIDI 입력은 구현 범위에 포함하지 않습니다.

## PWA와 알려진 제한

프로덕션 빌드에서만 `/sw.js`를 등록합니다. HTTPS 또는 허용되는 localhost 환경에서 서비스워커가 설치·활성화되어 앱을 제어한 뒤, 온라인으로 실제 요청해 캐시된 앱 페이지와 정적 자산만 오프라인에서 사용할 수 있습니다. 처음에는 온라인 방문이 필요하며, 설치 후 한 번 새로고침하고 필요한 화면을 열어 캐시해야 합니다. 첫 방문 전 전체 앱의 오프라인 실행, 아직 요청하지 않은 파일, 배포 플랫폼의 로그인 화면까지 오프라인으로 제공하지 않습니다. 개발 서버에서는 서비스워커를 등록하지 않습니다.

현재 브라우저 E2E는 Chromium 에뮬레이션을 대상으로 합니다. 실물 iOS Safari의 오디오 재개·PWA 설치와 Android 터치 환경은 아직 검증하지 않았습니다. 진행 중인 스테이지의 문항 위치는 저장하지 않으며, 스테이지를 나가거나 새로고침하면 해당 임무를 다시 시작합니다. 7th 코드, 전위, MIDI, 교사용 계정·학급 대시보드는 후속 확장 범위입니다.
